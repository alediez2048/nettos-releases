# ApplyPilot for Mac

Official ApplyPilot download and update channel for Apple Silicon Macs running macOS 13 or later.

Installers and signed updater files are published under [Releases](https://github.com/alediez2048/applypilot-releases/releases). No releases are available until the first build passes signing, notarization, and review.

This repository contains release artifacts and public release notes. Development and build workflows are maintained separately.
